# Controlling AR10 Hands via fNIRS Motor Imagery

## Overview

This project explores multimodal robotic hand control using:

- fNIRS-based motor imagery decoding
- Webcam-based hand tracking
- Real-time actuator control

## Technical Stack

- Python
- OpenCV
- MediaPipe
- Machine learning classifiers
- Serial / ROS interface
