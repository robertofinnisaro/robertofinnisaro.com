## Direction

The site combines modern editorial layouts with an archival visual language: warm metal accents, dark forest tones, cartographic geometry and restrained motion.

## Architecture

Astro generates static pages from typed Markdown collections. Git provides history and Cloudflare Pages handles builds and hosting.
