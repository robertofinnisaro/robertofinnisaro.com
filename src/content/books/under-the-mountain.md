*Working title.*

This book follows the build of Project Erebor, a home server rack, from the first planning decisions through to day-to-day operation. It works through every layer of the rack in depth: the hardware, the network and its protocols, storage, virtualisation, the services that run on top, and the practices that keep it all running.

Each chapter is written to be followed in order. Detailed values such as addressing, VLANs, host configuration and procedures live in the accompanying reference library, so the chapters can explain decisions without being interrupted by tables of settings.
